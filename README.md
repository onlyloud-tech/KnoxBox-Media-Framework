# KnoxBox Media Framework

KnoxBox Media Framework (`KBM_Core`) is the shared foundation for KnoxBox Media mods in Project Zomboid Build 42. It provides the common interface code and Java bridge that let our mods display movie and Game Boy frames, play media audio, and share features across devices.

To use the Framework in game, install the Workshop mod alongside a compatible KnoxBox Media mod and its required dependencies.
